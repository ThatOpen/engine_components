# Projects

Drop IFC models into this folder to load them from the dev server.

## Layout

```
projects/
├── viewer.html / viewer.ts   # multi-model IFC viewer
├── <name>/
│   ├── model.ifc             # one directory per project
│   └── project.title         # optional display title (first line)
└── index.html                # optional gallery, generated by your tooling
```

Every directory that contains an `.ifc` file is listed on the dev server home
page and opens in `viewer.html`.

## Viewer

- **Add IFC…** — append one or more IFC files to the current scene.
- **Open IFC…** — replace the scene with the selected files.
- **Models panel** — list of loaded models with per-model hide/unload and a
  coordinate mode:
  - `shared (first model)` (default) — every model is moved into the
    coordinate system of the first loaded one
    (`position = coords_first − coords_i`, read from `model.getCoordinates()`);
  - `from each file` — keeps the per-file normalization web-ifc applied while
    loading (`COORDINATE_TO_ORIGIN`).
- Drag & drop also appends files.
- The page validates the IFC signature (`ISO-10303-21`) before conversion, so
  a wrong URL or a broken file shows an error instead of crashing the tab.

Models can be loaded straight from the URL, one `?model=` parameter per file:

```
projects/viewer.html?model=name-a/model.ifc&model=name-b/model.ifc&title=Project
```

For debugging, `window.__bim` exposes `{ components, world, fragments, ifcLoader }`.
